# Data Analysis Projects

A collection of SQL and Python data analysis projects covering data cleaning, exploratory data
analysis (EDA), and business-driven scoring/ranking logic across insurance, sports analytics,
venture investing, and entertainment datasets.

## Projects

### 🐍 Python / EDA — [`predictive modelling/`](./predictive%20modelling)

| Project | Summary |
|---|---|
| [Unicorn Companies — Investor Portfolio Analysis](./predictive%20modelling/investors-portfolio-project.md) | Analyzes 1,000+ global unicorn startups to identify the most attractive industries to invest in and the fastest companies to reach a $1B valuation. |
| [Rotten Tomatoes — Movie Ratings Analysis](./predictive%20modelling/movie-ratings-analysis.md) | Cleans and profiles 16,000+ movie records, fixing data-entry errors and missing values ahead of ratings analysis. |

### 🗄️ SQL — [`sql/`](./sql)

| Project | Summary |
|---|---|
| [Insurance Underwriting Risk Score](./sql/insurance-underwriting.md) | Builds a weighted, normalized underwriting risk score and risk tier per policy from six risk factors. |
| [MLB Player & Team Analytics](./sql/mlb-player-analysis.md) | Analyzes player pipelines, team spending, and career statistics using historical MLB data. |

## Skills Demonstrated

- **Data cleaning:** handling missing values, fixing malformed categorical labels, type coercion
- **Exploratory data analysis:** distribution analysis, grouping, ranking, trend analysis
- **SQL:** CTEs, window functions (`OVER`, `PARTITION BY`, `DENSE_RANK`, `NTILE`, `LAG`),
  conditional aggregation, multi-table joins
- **Python:** pandas, NumPy, seaborn, matplotlib
- **Business framing:** translating raw data into decision-ready scores and stakeholder insights
